# Security reporting

To report a security issue, use GitHub's private vulnerability reporting option if it is available on the [TeamBoard Security page](https://github.com/pedimmdi/teamboard/security). If the option is unavailable, contact a maintainer privately and ask for a secure channel. Public issues are appropriate for general bugs.

Include the affected version or commit, the components involved, the expected and observed behavior, and the impact. Use disposable data and redact credentials, private workspace content, personal information and deployment details. Maintainers determine triage and disclosure timing with the reporter.

TeamBoard's OAuth setup and supported MCP scopes are documented in the [MCP guide](docs/mcp-local.md).
